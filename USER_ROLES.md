# Role-Based Access Control (RBAC) Specification

| Role Code | Role Name | Primary Responsibility |
|:---|:---|:---|
| SUPER_ADMIN | Super Administrator | Full system configuration, audit logs, user role assignment. |
| MANAGER | Workshop General Manager | Operational oversight of all quotes, orders, inventory, and staff. |
| SALES | Sales Representative | Customer consultations, quotation generation, catalog updates. |
| PRODUCTION | Workshop Production Staff | Stage-by-stage manufacturing updates, material consumption. |
| ACCOUNTANT | Financial Accountant | Invoicing, payments verification (ETB), workshop expenses. |
| CUSTOMER | Client / Customer | Requesting quotations, placing orders, making payments, tracking jobs. |
