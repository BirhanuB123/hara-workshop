# End-to-End Business Workflow — Hara Workshop

`
[CUSTOMER]
1. Browse Catalog & Portfolio ->
2. Submit Custom Quote Request (dimensions, wood/metal type, reference images) ->
   
[WORKSHOP SALES / ESTIMATOR]
3. Review Request ->
4. Input Costing (Materials + Labor + Transport + Installation - Discount) ->
5. Send Proposed Quotation to Customer ->

[CUSTOMER]
6. Review Proposal -> Accept Quotation ->

[SYSTEM]
7. Auto-generate Order (HW-YYYY-XXXX) and Initial Invoice ->

[ACCOUNTANT]
8. Record Deposit / Payment (Telebirr / CBE / Cash) ->

[PRODUCTION SUPERVISOR]
9. Production Job Created -> 10 Stages:
   Order Confirmed -> Material Prep -> Cutting -> Fabrication -> 
   Assembly -> Finishing -> Quality Inspection -> Ready for Delivery -> 
   Installation -> Completed ->
10. Customer tracks progress in real-time ->
11. Final Inspection & Sign-off -> Delivery & Handover.
`
